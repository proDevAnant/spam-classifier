# 📩 Spam Email/SMS Classifier

A machine learning project that classifies text messages (SMS/Email) as
**Spam** or **Ham (not spam)** using Natural Language Processing + classical
ML algorithms, with a live Streamlit demo app.

## 2. About the Dataset

⚠️ **Important:** The `data/spam.csv` included here is a **synthetic,
template-based dataset** generated by `data/generate_dataset.py`. It was
created this way because this environment doesn't have internet access to
download the real dataset. It is realistic enough to demonstrate the full
pipeline working end-to-end, but because it's template-based, the model
scores unrealistically high (~100%) on it.

### For your final submission, use the real dataset:
1. Go to: **https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset**
2. Download `spam.csv` (it has ~5,500 real SMS messages, labeled spam/ham)
3. Replace `data/spam.csv` with the downloaded file
   (make sure columns are named `label` and `message` — rename if needed,
   the original Kaggle file uses `v1`/`v2`, so run:
   ```python
   import pandas as pd
   df = pd.read_csv("spam.csv", encoding="latin-1")[["v1", "v2"]]
   df.columns = ["label", "message"]
   df.to_csv("data/spam.csv", index=False)
   ```
4. Re-run `python train.py` — no other code changes needed.

Using the real dataset will give you realistic accuracy numbers (typically
~96–98%) which is much better to show in your project report/viva.

## 3. How to Run (Step by Step)

### Step 1: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 2: (Optional) Regenerate the sample dataset
```bash
python data/generate_dataset.py
```

### Step 3: Train the model
```bash
python train.py
```
This will:
- Load and clean the data
- Convert text to TF-IDF features
- Train 3 models: Naive Bayes, Logistic Regression, Linear SVM
- Pick the best one (by F1-score) and save it to `model/`
- Save evaluation plots to `outputs/`

### Step 4: Run the live demo app
```bash
streamlit run app.py
```
This opens a browser window where you can type any message and instantly
see whether it's classified as Spam or Ham.

## 4. How It Works (For Your Report)

1. **Text Preprocessing** (`preprocess.py`)
   - Lowercasing
   - Removing URLs, emails, punctuation, and numbers
   - Removing stopwords (common words like "the", "is", "and")

2. **Feature Extraction — TF-IDF**
   TF-IDF (Term Frequency–Inverse Document Frequency) converts text into
   numerical vectors, giving higher weight to words that are important/
   distinctive to a message and lower weight to very common words.

3. **Model Training**
   Three classic ML algorithms are trained and compared:
   - **Multinomial Naive Bayes** — works very well for text classification,
     fast and simple, based on word-frequency probabilities.
   - **Logistic Regression** — a linear classifier, good baseline.
   - **Linear SVM** — often very strong for high-dimensional text data.

4. **Evaluation Metrics**
   - **Accuracy** — overall % of correct predictions
   - **Precision** — of messages predicted spam, how many were actually spam
   - **Recall** — of actual spam messages, how many were correctly caught
   - **F1-score** — balance between precision and recall

5. **Deployment**
   The best model + vectorizer are saved with `joblib` and loaded into a
   Streamlit web app (`app.py`) so a user can test messages live.
